# Security Policy

## Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| `< 1.0` | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Job Agent, please follow responsible disclosure:

1. **Do not open a public issue.**
2. Send a private report to the maintainer via GitHub security advisory or direct email to the project administrator at [github.com/Mhmd7syn](https://github.com/Mhmd7syn).
3. Include detailed information:
   - Description of the vulnerability.
   - Proof-of-concept script, reproduction steps, or request/payload samples.
   - Potential impact on users, credentials, or local environment.
4. We will acknowledge receipt of your report within 48 hours and provide a timeline for triage and resolution.
5. Once a fix is verified, a patched release or commit will be published along with appropriate credit to the reporter.
